坐标如何计算？

以 1 为原点 (0,0)，向右为 +x，向上为 +y。2 在 (1,0)，3 在 (1,1)，4 在 (0,1)。层数 k = max(|x|, |y|)。

给定正整数 m，层数为 k = ⌈(√m − 1) / 2⌉，其中 ⌈ ⌉ 表示向上取整。m = 1 时，k = 0，坐标为 (0, 0)。

当 m > 1 时，令 M = (2k + 1)²，d = M − m，坐标由下表直接计算：

条件xy
0 ≤ d < 2kk − d−k
2k ≤ d < 4k−kd − 3k
4k ≤ d < 6kd − 5kk
6k ≤ d < 8kk7k − d

例如 m = 97：k = 5，M = 121，d = 24，属于 4k ≤ d < 6k，因此坐标为 (−1, 5)。公式适用于所有正整数，当前交互图支持到 1,002,001。

为什么会出现斜线？

螺旋的部分斜线对应二次多项式数列，其中一些数列包含较多质数。放大后可以看见离散的点，缩小后则形成醒目的对角纹理。

图案不是猜想的证明

此图按乌拉姆螺旋制作，使用筛法计算实际质数，不以黎曼猜想或孪生素数猜想成立为前提。有限范围的图像不能证明关于无限多个质数的命题。
